# Автоателье | Пермь

Сайт-концепт для автоателье в Перми: перетяжка руля и сидений, восстановление боковой поддержки, салоны авто, катера и спецтехника.

## Стек

Статический сайт: HTML / CSS / JS. Без сборки.

## Локально

Откройте `index.html` в браузере или поднимите любой static server:

```bash
npx --yes serve .
```
